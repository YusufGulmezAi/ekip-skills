# Bilesen spesifikasyonu

## GB12 — Liste sayfasi deseni (onaylandi 02.10.2026)
- Ust satir: `SayfaBasligi` + sagda "Yeni" dugmesi.
- Altinda `FiltreCubugu` (arama kutusu), sonra `Tablo` (sayfa boyutu 10) ve `Sayfalama`.
- Bos durum: `BosDurum` bileseni, "Henuz kayit yok" metni.
- Satira tiklayinca detay sayfasina gider (`/{kod}`).
